Firmware installer Beta

Install the published firmware on a CH552 macropad using desktop Chrome or Edge. No PlatformIO or Arduino installation needed.

Beta prototype — macOS tested and verified. Windows and Linux hardware validation is still pending, but should work after following Step 1

1. Prepare your computer

Choose your platform for USB access instructions. The bootloader is a separate USB device from your normal keyboard.

Windows

WebUSB requires the WinUSB driver for the bootloader. If connecting fails, download Zadig from its official site.

  1. Put the macropad in bootloader mode using Step 2. Note: the chip automatically exits bootloader mode after 8-10 seconds without communication, so you will need to be somewhat quick
  2. In Zadig, choose Options → List All Devices.
  3. Select only the bootloader with USB ID 4348:55E0 (it may be called “Unknown device” or “USB Module”). Do not select your normal keyboard or “Universal Macropad”.
  4. Select WinUSB, then Install/Replace Driver. Administrator access is required.
  5. Return here and connect. This driver change may affect other native WCH programming tools.
  6. Optional: when you are done uploading the firmware, you can remove WinUSB following the official Zadig guide.

Sources: Chrome: Windows WebUSB requirements · Official Zadig guide

macOS

Tested and verified: firmware installation on macOS, including boot configuration readback, firmware verification, and preservation of on-device profiles in DataFlash.

No additional USB driver is normally needed. Close other firmware upload tools that may be using the device, then connect its bootloader here.

Source: Chrome: macOS WebUSB requirements

Linux

If the picker lists the bootloader but opening it fails with a permission error, a udev rule may be needed. Ask your administrator to grant your account access to USB device 4348:55e0.

On systems with a plugdev group, put this device-specific rule in /etc/udev/rules.d/70-ch552-bootloader.rules:

SUBSYSTEM=="usb", ATTR{idVendor}=="4348", ATTR{idProduct}=="55e0", MODE="0660", GROUP="plugdev"

Ensure your account belongs to that group (check with id -nG). An administrator can add it with sudo usermod -aG plugdev "$USER"; log out and back in afterward. Group names vary by distribution.

Reload rules with sudo udevadm control --reload-rules, then unplug the device and reconnect it in bootloader mode. Do not run your browser as root.

Sources: Chrome: Linux WebUSB permissions · udev rule documentation · udevadm documentation

2. Enter bootloader mode

If this project's firmware is already installed, entering bootloader mode is easy: unplug USB, hold the encoder button, and reconnect USB while keeping it held down. The LEDs will turn red. If the optional encoder long-press bootloader entry mode is enabled for the macropad's current layer, hold the encoder button for 3 seconds while the device is powered on. The LEDs will also turn red

With the stock firmware, follow the hardware bootloader instructions on this project's GitHub page. This requires you to unscrew the acrylic plates and physically connect two pins with a button or metal tweezers.

Once in bootloader mode, your browser will allow you to connect to the macropad. Note: the chip automatically exits bootloader mode after 8-10 seconds without communication, so you will need to be somewhat quick.

Supported by this beta: CH552, bootloader versions 2.3.1-2.5.0.
